### 3.2 GitHub Actions 工作流文件（`.github/workflows/`）

| 文件 | 触发 | 内容 |
|---|---|---|
| `backend-ci.yml` | `pull_request`（含 fork）+ `push` main | Ubuntu runner；Java 21；Maven Wrapper；Maven 依赖缓存；`backend/` 下 `./mvnw clean verify`；Testcontainers Docker 环境（Docker 服务）；`git diff --check`；测试报告归档（surefire-reports）；`timeout-minutes` 上限 |
| `repository-security.yml` | `pull_request` + `push` main + schedule（如允许） | Secret Scan（Gitleaks，固定版本）；SCA/容器漏洞（Trivy，固定版本）；CycloneDX SBOM（Maven 插件固定版本）；License 合规扫描；结果以 **SARIF/Artifact** 输出；**扫描失败与工具基础设施失败必须区分**（禁止"未执行却显示通过"）；工具与规则版本固定 |
| `dependency-review.yml` | `pull_request`（dependency-review 事件；权限允许时） | GitHub Dependency Review；不获取额外写权限 |
| `workflow-lint-security.yml` | `pull_request` + `push main` | `actionlint`（固定版本）校验 Workflow YAML；检查危险权限/可变 Action 引用/`pull_request_target`/Secret 暴露风险 |

### 3.3 权限矩阵（公开仓库最小权限）

- **默认 `permissions: contents: read`**（workflow 级 + Actions 设置）。
- `backend-ci`：`contents: read`（无需写）。
- `repository-security`：`contents: read`；SARIF 上传需要 `security-events: write`（仅当可配置时授予，
  否则以 Artifact 输出）；不读任何 Repository/Environment/组织 Secret。
- `dependency-review`：`contents: read` + `pull-requests: read`。
- `workflow-lint-security`：`contents: read`。
- **任何 Job 不得** push、发布 Package、签名、部署、发表评论或修改仓库。

### 3.4 Fork 威胁模型（公开仓库不可信代码）

- **禁止 `pull_request_target` 执行 PR 提供的代码**；不可信 PR 仅用 `pull_request` 事件（fork 上隔离环境）。
- Fork PR 工作流**不得读取** Repository/Environment/组织 Secret。
- 不得为获取 Secret 使用危险事件或检出并运行 Fork 代码。
- 真实 Provider（DEEPSEEK/OPENAI）、DM8、Renderer、部署、签名等需要 Secret/受控环境的测试
  **不得在不可信 PR 中执行**（标记 NOT_APPLICABLE_YET / BLOCKED）。
- **Actions 固定到不可变 commit SHA**（注释保留版本名称，如 `# actionlint v1.7.7`）；禁止 `@main/@master/可变 tag`。
- 第三方 Actions 进入供应链清单（THIRD-PARTY-NOTICES + SBOM）。

### 3.5 Required Checks 名称（实施后真实运行成功才设 Required）

- 候选：`backend-ci`、`repository-security`、`workflow-lint-security`（如可配置）。
- 仅将**真实存在且成功运行**的检查设为 Required；**未建立的未来 Gate 不写成 Required Check**。

### 3.6 扫描工具及固定版本策略

| 工具 | 版本策略 | 说明 |
|---|---|---|
| Gitleaks | 固定版本 + commit SHA | Secret Scan；本地可复现（`gitleaks detect`） |

| License 扫描 | 基于 SBOM + 固定规则集 | 与 THIRD-PARTY-NOTICES 交叉校验 |
