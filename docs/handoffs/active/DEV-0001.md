## 2. 唯一目标

建立长期保留的 Java 21 + Spring Boot 4.1.0 + AgentScope Java 2.0.1 兼容性测试模块，验证真实 Harness/Core 的构建、启动、最小执行、Typed Event、结构化结果、取消、错误传播、长期 Runtime Identity 与 Recovery，并形成 AgentScope Adapter 能力清单。

## 3. 明确排除

- 不实现 Workspace、Task、Skill、Knowledge、Artifact、Approval 或 Renderer 业务模块。
- 不接入正式业务数据库模型。
- 不自研 Agent Runtime、Workflow、Memory、Tool Framework 或模型协议层。
- 不使用 Mock/Fake 冒充 AgentScope 集成。
- 不静默降级 Java、Spring Boot 或 AgentScope 版本。
- 不引入自动长期记忆（Long-Term Memory）能力（需独立 ADR）。

## 4. 设计与不变量

- 模块职责：验证核心组合是否可作为 V1 长期后端基线。
- 调用链：Spring Bean → Nexus Edge Adapter Port → AgentScope Harness/Core → 官方 Provider/Test Endpoint → Typed Event/Result。
- 不变量：所有 Agent 执行能力来自 AgentScope 官方 API；PoC 代码可持续进入 CI，不是验证后删除的脚本。
- Schema/API/Event/State 影响：预计无业务 Schema 和公共 API；只形成适配层内部契约与兼容证据。
- 长期 Runtime Identity（P0-1/P0-4）：`AgentRuntimeIdentityMapper` 把 Tenant/Workspace/User/Session 映射为稳定、无碰撞、路径安全的 AgentScope `scopedUserId`/`scopedSessionId`；原始业务 ID 保留在 RuntimeContext extras。
