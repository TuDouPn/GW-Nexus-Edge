## 2. 唯一目标

在 **Java 21 + Spring Boot 4.1.0 + AgentScope 2.0.1 固定不变**前提下，验证并冻结 G-02 外围依赖
（MyBatis-Plus、Sa-Token、MySQL/PostgreSQL/DM8 JDBC、Redis Client、Flyway），输出精确版本、
依赖树、冲突、排除项、升级风险，经 ADR-0007 冻结，更新 G-02 状态。

## 3. 明确排除

- 不降级核心版本；不替换冻结架构；不开发业务功能；不写 Mock/占位/虚假结论。
- Compatibility Harness（`nexus-edge-compatibility-test`）不进入生产镜像/运行时依赖，不被生产模块依赖。
- DM8 无合法服务器环境 → 如实 BLOCKED，不伪造通过；不借用 MySQL 结果。
- 不处理 G-03 剩余项、Coding 基础设施或其他 OQ。

## 4. 设计与不变量（执行要点）

- 版本选择规则：Spring Boot 4.1.0 BOM 优先；官方 Spring Boot 4 Starter 优先；不以「最新」为依据；
  覆盖 BOM 必须原因 + 测试证据。
- 测试为真实集成（Testcontainers 固定版本镜像 + 官方驱动/Starter），无 Mock/H2/固定 JSON/仅 Bean 存在。
- DM8 独立 Profile（`-P dm8-compat`）；禁 systemPath、禁提交商业驱动。
