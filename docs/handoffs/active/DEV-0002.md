## 2. 唯一目标

在 **Java 21 + Spring Boot 4.1.0 + AgentScope Java 2.0.1 固定不变**的前提下，验证并冻结 G-02 要求的外围依赖版本：

- MyBatis-Plus
- Sa-Token
- MySQL JDBC Driver
- DM8 JDBC Driver（兼容认证范围）
- PostgreSQL JDBC Driver
- Redis Client（Lettuce/Redisson 评估后冻结）
- Flyway

产出：最小真实 Spring Boot Compatibility Harness、真实集成测试、精确版本与依赖树、已知冲突/排除项/升级风险、ADR-0007 冻结、G-02 状态更新、兼容性报告。

## 9. 风险和阻塞

- **DM8 JDBC Driver / 环境可获得性**：若无法获得合法驱动或 DM8 环境，如实标记 BLOCKED/PARTIAL，不伪造通过。
- **Sa-Token 与 Spring Boot 4.1.0 / Servlet 版本兼容性**：需真实装配验证；若 Starter 与 SB 4.1.0 不兼容，按 ADR 记录并给出排除/替代方案，不静默降级核心。
- **MyBatis-Plus 与 Spring Boot 4.1.0 自动装配**：版本差异可能导致装配冲突，需 dependency:tree 与真实启动验证。
- **Flyway 版本与 MySQL/DM8 支持矩阵**：MySQL 8.x/9.x 支持范围需核验；DM8 需独立验证或如实标记。
- **Testcontainers 需要 Docker**：本机 Docker 可用；CI（G-06）尚未建立，本地验证为证据来源。
- **网络访问**：Maven Central 与容器镜像拉取需要网络；阻断时如实报告。
